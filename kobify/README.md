# KOBIFY / 万物皆可科比

[在线使用](https://silicastra.github.io/kobify/)

上传图片，将它的色块重新排列，尽量拼出科比，并播放粒子流动动画。图片只在浏览器中解码和计算，不上传服务器，不需要账号、API key 或后端。

## 来源与实现

基于 [Spu7Nix/obamify](https://github.com/Spu7Nix/obamify) 的 MIT 开源实现移植，参考提交 `36895595b54c16db496ee4a5d903d5eb80000186`。保留原作者版权及完整 LICENSE。

这是 JavaScript/WebGL2 移植版本，不是原 Rust/WASM 程序的重新编译：

- `matching-source` 对应原项目 `src/app/calculate/mod.rs` 的贪心像素对交换。颜色平方差加空间位移惩罚，交换仅在总代价下降时接受；使用缩小搜索半径的 150 轮搜索，Worker 中执行。源像素与目标位置始终一一对应。未移植 Hungarian 方法和人脸权重图。
- `simulation-source` 参考 `src/app/morph_sim.rs` 的目标吸引、邻居排斥、速度对齐和空间哈希。采用固定步长、插值目标和最终归位；这是视觉粒子模拟，并非完整流体求解器。
- `renderer-source` 使用 WebGL2 种子绘制与 Jump Flooding 最近粒子填色，缺少 WebGL2 时降级为 Canvas 2D 色块绘制。
- 目标改为用户提供的科比照片；演示输入明确标注为打散的目标照片。上传文件始终使用其自身像素。

## 使用

1. 上传 JPG、PNG、WEBP、AVIF 或 GIF（GIF 取浏览器解码的静态帧），最大 20 MB。
2. 首页沿用 HARD MODE 的大幅背景和左侧上传面板。五档滑轨控制实际重排精度：低 32×32、中 48×48、高 64×64、极高 96×96、max 128×128；背景随档位切换，重排目标始终是原始科比照片。“更多设置”可调整裁剪和原图结构保留程度。
3. 点击“开始重排”进入 `#result` 二级结果界面，计算完成后自动播放像素流动动画并停在成品；可暂停、拖动进度、对照原图、导出当前画面 PNG。返回调整会停止后台计算/动画并保留输入与档位；刷新时图片不会持久保存，需要重新选择。
4. 默认“目标配色”为 0%，保留经过裁剪/缩放/透明背景合成后的输入色块颜色。提高该值会显式混合目标照片颜色；100% 最终颜色完全来自目标。

纯重排不能创造原图没有的颜色，因此纯色图、颜色分布差异大的图不一定形成清晰人像。“任何图片”指支持的图片都能作为输入，不承诺仅靠重排就完美还原目标。减小“保留原图结构”更偏向目标外观。

## 向作者反馈

页脚“向作者反馈”打开反馈窗口，由 Cloudflare Workers 接收并保存到作者的 D1 数据库。联系方式选填，不上传图片或密钥。后端部署与作者查看说明见 [feedback-api](../feedback-api/README.md)。

## 像素映射与还原密钥

计算完成后，可点击“反向播放”，沿同一像素映射从成品流回输入排列。也可以下载 JSON 格式的“图像还原密钥”和配套的“可还原成品”PNG。首页与结果页均可导入这两个文件，在浏览器中精确还原并下载输入像素图。

密钥字段：`format: kobify-pixel-key`、`version: 1`、`size`、`destinationToSource`（左上角起、逐行排列；目标位置对应的源像素索引）、`resultSha256` 和 `originalSha256`（RGBA 字节的 SHA-256）。密钥没有原图像素数据，不是密码学加密。位置映射会随图片或设置重新计算，应成对保存。

“可还原成品”直接导出 n×n 的最终排列，不受当前播放进度、目标配色或 WebGL 渲染影响。普通预览下载、JPEG、调色或改尺寸后的图片不能用于精确还原；尺寸与颜色校验不通过时会拒绝还原。恢复范围是本次裁剪、缩放、白底合成后的 n×n 输入，不包括原始大图的细节和裁剪区域。

## 开发与测试

所有代码和目标照片嵌入 `index.html`，没有外部运行依赖。模块以带 ID 的 script 分段，便于编辑和提取测试。GitHub Pages 直接从主分支发布。

```sh
python -m http.server 4174
# 打开 http://localhost:4174/
node tests.mjs
```

测试检查置换不变量、优化目标不增加、确定性、同图与纯色输入、错误输入、粒子边界以及动画端点。WebGL、上传、取消、导出和响应式布局需要在浏览器中验证。
